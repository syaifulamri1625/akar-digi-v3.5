## 📌 **Tentang Aplikasi**
**AKAR-DIGI V3.5** adalah sistem manajemen arsip digital berbasis web yang terintegrasi langsung dengan Google Drive dan Google Sheets. Aplikasi ini dirancang khusus untuk mempermudah pendidik, kepala sekolah, asesor, dan tenaga kependidikan dalam mengelola, memantau, serta mengunggah bukti fisik instrumen akreditasi sekolah secara terstruktur, transparan, dan akurat.

---

## 🚀 **Fitur Unggulan**
* **📅 Manajemen Multi-Tahun Ajaran:** Pengarsipan dokumen dikelompokkan secara spesifik berdasarkan tahun ajaran (mulai dari TA 2022/2023 hingga TA 2026/2027).
* **🔐 Hak Akses Berbasis Peran (*Role-Based Access*):** 
  * *Guru / Pengampu:* Akses penuh untuk mengunggah berkas instrumen.
  * *Admin:* Pengelolaan dan kontrol penuh sistem.
  * *Asesor / Verifikator:* Akses khusus *Read-Only* untuk memverifikasi dan melihat tautan folder Drive.
* **📊 Matriks Pemenuhan Live:** Pemantauan status kelengkapan sub-standar akreditasi secara *real-time*.
* **📄 Pusat Laporan Resmi (PDF):** Generator otomatis laporan rekapitulasi audit bulanan dan tahunan dalam format PDF.
