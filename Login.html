Standar Penamaan File Akreditasi

SMK Negeri 1 Gunung Sindur

💡 Mengapa penamaan file harus seragam? Agar asesor dan tim penjaminan mutu dapat dengan cepat mendeteksi kepemilikan, isi dokumen, serta tahun ajaran arsip bukti fisik tanpa harus membuka file satu persatu.

1. Kode Singkatan Program Keahlian

BP : Broadcasting & Perfilman
TM : Teknik Pemesinan
Elin : Elektronika Industri
TJKT : Jaringan Komputer
TKR : Kendaraan Ringan

2. Format Baku Penamaan File

[KODE_SUB]_[JURUSAN]_[NAMA_GURU]_[KETERANGAN]_[TA]

Contoh: 2.1_BP_SyaifulAmri_ModulAjar-TataCahaya_TA2627.pdf (Gunakan tanda hubung/garis bawah tanpa spasi).

3. Contoh Penerapan Berdasarkan Standar

Standar 1 (Kurikulum / KSP): 1.1_BP_SyaifulAmri_KSP-FilmLab_TA2627.pdf
Standar 2 (Modul Ajar / RPP): 2.1_TKR_AhmadDahlan_ModulAjar-Chasis_TA2627.pdf
Standar 3 (Penilaian / Kisi-kisi): 3.2_TJKT_BudiSantoso_KisiKisiSoalPAS_TA2627.pdf
Standar 7 (Keuangan / SPJ): 7.3_TM_EkoSusanto_SPJPraktikumCNC_TA2627.pdf
Standar 8 (Kerjasama DUDI / Industri): 8.1_Elin_SitiAminah_MoUDUDI-PTInova_TA2627.pdf
📌 Catatan Penting: Pastikan dokumen akhir telah dikonversi ke format .pdf sebelum diunggah agar tata letak file aman dan mudah diverifikasi oleh asesor.
